# 安全规程

> 本机器涉及 **X 射线辐射**、**380V 高压**、**0.6 MPa 高压气**、**重型旋转机械**。  
> 操作员必须签字阅读本文件后方可上岗。

## 一、辐射安全（最严）

### 法规依据
- GBZ 117《工业 X 射线探伤卫生防护标准》
- GB 18871《电离辐射防护与辐射源安全基本标准》

### 设备规格
- 型号：VJ Technologies IXS200BP500P479
- 最大管电压 200 kV，最大管电流 2.5 mA，最大功率 500 W
- 焦点 0.8 mm，锥形束 60°
- 防爆箱外加 1.5 mm Ultem + 5 mm UHMW PE 屏蔽

### 必须遵守
1. **持证上岗**：放射工作人员证 + 个人剂量计
2. **互锁回路**：J2 Pin 1 & 2 必须通过门控开关串联，门开高压必断
3. **警示标识**：黄色三角辐射符 + "禁止入内" + 蜂鸣器
4. **辐射工作区**：操作位剂量率 < 0.5 μSv/h（每月一测）
5. **应急**：发现剂量计异常 → 立即关 X 射线 → 撤离 → 联系厂家

### 禁止
- 通电时打开任何防爆箱
- 通电时拆装电缆
- 改装屏蔽材料
- 操作员未戴个人剂量计上岗

## 二、电气安全

### 必须遵守
1. 主回路打开必须先断刀型隔离器，万用表确认无电
2. 24V 控制电与 380V 动力电分柜走线
3. 配电柜钥匙由专人保管
4. 故障复位前必须先排查根因
5. 急停按钮 ≥ 2 个，操作位 3 秒内可达
6. 接地电阻 < 4 Ω，每年一测

### 禁止
- 带电操作
- 跨接急停回路
- 私拉电线
- 湿手操作

## 三、气路安全

### 必须遵守
1. 0.6 MPa 工作压力，不得超过 0.8 MPa
2. 储气罐每天排水，每年送检
3. 喷嘴方向严禁站人或放工具
4. 安全阀必须可靠，不得封死
5. 维修气路前先关气、放压、挂牌

### 禁止
- 人体或眼睛对准喷嘴方向
- 用气枪吹身体或衣服
- 改装减压阀

## 四、机械安全

### 必须遵守
1. 皮带运行时严禁伸手或靠近
2. 维修必须先停机 + 上锁挂牌（LOTO）
3. 防护罩齐全后才能启动
4. 振动分筛运行时不得攀爬
5. 重物吊装由专人操作

### 禁止
- 在皮带上行走或坐卧
- 在运行中调整张紧装置
- 单人吊装大件

## 五、应急预案

### 5.1 X 射线泄漏
- 立即按急停 → 撤离至 3m 外 → 联系辐射安全员 → 查互锁回路

### 5.2 火灾
- 切断主电源 → 用 CO2 或干粉灭火（**不得用水**）
- 拨打 119

### 5.3 触电
- 切断电源 → 不可用手直接拉伤员
- 用绝缘物拨开后施救

### 5.4 高压气泄漏伤人
- 立即停气 → 检查呼吸 → 高压气进入皮下需立即就医

### 5.5 急停按钮失效
- 立即拉总闸 → 锁柜门 → 联系电气工程师
