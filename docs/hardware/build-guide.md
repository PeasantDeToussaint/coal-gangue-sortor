# 硬件搭建手册（从空机柜到通电）

> 本手册基于太原泓博科技实物（合同 C-2024000002）整机，按真实供方拆分为 13 个步骤。  
> 每一步都有验证标准，**通过验证才能进下一步**。  
> 新人工程师建议跟着师傅做完整一遍，全程拍照存档到 `docs/hardware/photos/`。

## 总览

整机由 5 大子系统组成，按以下顺序搭建：

```
   ① 机械本体（泓博自加工）
        ↓
   ② 气路系统（空压机 + 储气罐 + 分气排 + 电磁阀 + 喷嘴）
        ↓
   ③ X 射线模块（VJ Technologies + Detection Technology）
        ↓
   ④ 配电柜 + 控制系统（山西天朗 + Beckhoff TwinCAT）
        ↓
   ⑤ 上位机软件（本仓库）
        ↓
   现场标定 + 试运行
```

## 步骤 1：机械本体装配

**目标**：把 SolidWorks 装配体 `煤矸总装.SLDASM` 物理实现。

**子步骤**：
1. 立柱 + 底座焊件 → 主框架（参考 `底座.SLDASM`）
2. 上下输送带（电机 + 减速箱 + 链条 + 滚轮）
3. 中间检测段（绿色 PVC 平皮带，约 2 m × 1 m）
4. X 射线龙门架（从 `光机H臂.SLDASM`）
5. 探测器安装架（从 `探测器防爆箱.SLDASM`，**注意防爆等级**）
6. 气枪龙门架（推荐方案三：`气枪龙门架.SLDASM`）
7. 报警三色灯立柱

**验证**：
- [ ] 整机水平（用气泡水平仪测皮带表面）
- [ ] 滚轮无偏摆（手动转动 1 圈无卡顿）
- [ ] 接地铜排已焊接
- [ ] 用记号笔在皮带上标基准点（标定时用）

**预计工时**：3–5 天（车间师傅主导）

## 步骤 2：气路系统

**目标**：从空压机到喷嘴，0.6 MPa 高压气路畅通。

**子步骤**：
1. 空压机就位（独立厂房，远离粉尘）
2. 储气罐 + 排水阀 + 安全阀
3. 主管路（DN25 不锈钢管或耐高压软管）
4. 进气过滤器 + 油雾分离器 + 减压阀（**0.6 MPa**）
5. 分气排安装到龙门架（参考手稿：860 mm × 26 孔 × 30 mm 间距）
6. DF8 电磁阀阵列连接到分气排（8 个模块 × 4 路 = 32 路，扩展可达 64 路）
7. 气嘴（铜+尼龙）拧入分气排底部
8. 气路打压试验（吹皂泡测漏，**每个接口都测**）

⚠️ **安全**：
- 打压前确认所有接头拧紧
- 操作员远离喷嘴方向
- 储气罐排水阀每天放水

**验证**：
- [ ] 主管路压力表稳定 0.6 MPa
- [ ] 关闭气源后 5 分钟压降 < 0.05 MPa
- [ ] 32 个电磁阀单独通 24V 都能听到"咔嗒"声

**预计工时**：1–2 天

## 步骤 3：X 射线模块

⚠️ **辐射安全前置**：
- [ ] 现场必须有持证辐射安全员
- [ ] 所有人员佩戴个人剂量计
- [ ] 防爆箱外加贴黄色辐射警示标
- [ ] 互锁回路（J2 Pin 1 & 2）必须通过门控开关串联

**子步骤**：
1. 探测器（X-GCU GT + 17 块 X-Card）安装到 `探测器防爆箱`
   - 用 14 根 14p 短跳线菊花链连起 17 块 X-Card
   - X-GCU GT 接 GigE 网线（蓝色）+ 24V 电源 + 触发线（15m）
2. X 射线源 IXS200BP500P479 安装到 `光机防爆箱`，对准探测器
   - 检查焦点距离（约 174.6 mm，参考 SPC-P479 figure 1）
   - 锥形束 60° 覆盖整个探测器宽度
3. 控制盒 ZS3000-011 装到配电柜或独立机柜
   - AC 230V 输入到 J1
   - RS232 接 PC（J3，9 针母口）
   - 联锁回路接 J2（Pin 1 & 2 通过安全门开关串联）
4. 触发线（15m）从 EL2828 某通道引到 X-GCU GT 的触发输入

**验证**：
- [ ] 控制盒 LED：Power 绿亮，X-ray On 红灭
- [ ] 给 J2 短接，发 `<STX>ENBL1<CR>` → X-ray On 红亮（**辐射安全员陪同**）
- [ ] 关好门，X-ray On 必须立即灭（互锁有效）
- [ ] 用 PC ping X-GCU 的 IP，能响应
- [ ] 用 SDK 自带 demo 程序拍一张暗场图，看 17 块卡的输出是否连续

**预计工时**：1 天 + 0.5 天辐射安全验收

## 步骤 4：配电柜与 Beckhoff 控制系统

**子步骤**：
1. 配电柜 GGD 800×2200×600 就位
2. 主回路：380V 三相五线进刀型隔离器 → 接触器 → 各电机
3. Beckhoff 模块装到 DIN 导轨：
   ```
   FC9022（在工控机里，不在柜内）
       ↓ 光纤
   EK1501 → EL9410 → EL2828 ×20 → EL9011 → EL6070 → EL9011
   ```
4. EL2828 通道分配（参照 [`io-table.md`](io-table.md)）：
   - 通道 1–64 → DF8 电磁阀（24V 直驱）
   - 通道 65–72 → 6 个皮带启停 + 振动分筛
   - 通道 73–80 → 三色灯 + 蜂鸣器 + 备用
   - 通道 81–96 → 变频器使能、故障复位
5. 24V 控制电源（NDR-240-24，独立于动力电）
6. 三色信号塔接 EL2828
7. 急停按钮（≥ 2 个）接 EL1xxx DI + 主回路安全继电器
8. 工控机：
   - 安装 Windows 10 IoT 或 TwinCAT/BSD（推荐）
   - 装 TwinCAT 3 Engineering + Runtime（注册码 00386449）
   - 把 FC9022 PCIe 卡装入工控机槽
9. PLC 工程师导入 GVL（参照 [`beckhoff-ads.md`](protocols/beckhoff-ads.md)）
10. 路由表配置（PC ↔ TwinCAT 都加上对方的 AMS Net ID）

**验证**：
- [ ] 上电先合 24V 控制电，再合主动力电（顺序不能反）
- [ ] TwinCAT System Manager 看到 EtherCAT 网络上线，所有从站绿灯
- [ ] EL2828 1–64 通道用 ADS 工具逐个置位，听到对应电磁阀响
- [ ] 三色灯单独点亮 OK
- [ ] 按急停 → 主回路断开 + 三色红灯亮 + 蜂鸣

**预计工时**：2–3 天

## 步骤 5：上位机软件部署

**子步骤**：
1. 把本仓库 clone 到工控机
2. 装 Qt 6（参考 [`gui-build.md`](../gui-build.md)）
3. 装 Beckhoff/ADS 库：`git clone https://github.com/Beckhoff/ADS third_party/ads`
4. 拷贝 Aurora SDK：把旧项目 `include/DetInclude/` 复制到 `third_party/aurora-sdk/include/`，并联系地太科特要 `xlib.dll`
5. CMake 配置：
   ```bash
   cmake -B build \
     -DCGS_BUILD_GUI=ON \
     -DCGS_HAS_BECKHOFF_ADS=ON -DCGS_BECKHOFF_ADS_DIR=third_party/ads \
     -DCGS_HAS_AURORA_SDK=ON -DCGS_AURORA_SDK_DIR=third_party/aurora-sdk \
     -DCGS_HAS_SERIAL=ON
   cmake --build build -j
   ```
6. 编辑 `config/config.xml`（从 `config.example.xml` 复制，**填实际 IP / AMS Net ID / COM 口**）
7. 启动：
   ```bash
   ./build/app/coal_gangue_sorter_gui --real
   ```

**验证**：
- [ ] GUI 启动无报错
- [ ] 瀑布图能看到 X 射线流（探测器在采）
- [ ] 喷嘴矩阵全灰（未武装状态）
- [ ] 状态栏显示"未武装"
- [ ] 点"启动 / 武装"，状态变绿

**预计工时**：1 天

## 步骤 6：现场标定

**子步骤**：

### 6.1 皮带速度标定
- 沿皮带方向贴两个光电（间距 D = 850 mm）
- 在皮带上贴标定块
- 各档变频频率（20/30/40/50 Hz）下记录通过两个光电的时间差
- 用 [`tools/calibrate_belt.py`](../../tools/calibrate_belt.py) 拟合 Hz↔m/s

### 6.2 几何距离标定
- 卷尺量 X 射线探测中心到喷嘴中心 `L_sd`（mm）
- 写到 `config.xml` `<sensorToNozzleMm>`

### 6.3 喷嘴时序标定
- 用 [`tools/timing_simulator.py`](../../tools/timing_simulator.py) 看不同速度下推荐延时
- 实地放标定块，反复调 `valveOpenLatencyMs` 直到喷射准确命中

### 6.4 阈值标定
- 把已知煤+矸石样本逐个上皮带
- 看瀑布图标红的位置是否对
- 调 `xrayCoalMin` / `xrayGangueMax` 直到分类正确率 > 95%

### 6.5 喷嘴自检
- 跑 [`tools/nozzle_self_test.py`](../../tools/nozzle_self_test.py) 确认 64 路无遗漏

**验证**：
- [ ] 试运行 10 块煤 + 10 块矸石单独测试，识别率 ≥ 95%
- [ ] 试运行 5 煤 + 5 矸混合，喷射准确率 ≥ 90%
- [ ] 24 小时空载稳定测试无异常

**预计工时**：1–2 天

## 上电顺序（每天必背）

```
开机：
  ① 合 24V 控制电
  ② 合主动力电
  ③ 启动工控机 + TwinCAT Runtime
  ④ 启动空压机，等气压稳到 0.6 MPa
  ⑤ 启动 GUI 程序
  ⑥ 操作员关上 X 射线安全门（互锁通）
  ⑦ 启动 X 射线高压（GUI 上点"启动"按钮）
  ⑧ 等预热 30 秒
  ⑨ 武装系统（红色按钮变绿）
  ⑩ 启动皮带

关机：反向，先停皮带 → 解除武装 → 关 X 射线 → 退 GUI → 关空压机 → 关动力电 → 关控制电
```

## 常见故障速查

| 现象 | 可能原因 | 排查 |
|---|---|---|
| X 射线打不开 | J2 联锁未通 | 用万用表测 J2 Pin 1-2 通断 |
| 探测器无数据 | GigE 网线松 / IP 配错 | ping X-GCU IP；看交换机灯 |
| 喷嘴不响 | 24V 没到 / EL2828 没置位 | 用万用表测 EL2828 端子电压 |
| 喷射时机偏 | 几何参数错 / 皮带速度反馈错 | 重新走 6.1 + 6.2 |
| EtherCAT 报错 | 末端盖帽没装 / 跳线断 | 检查 EK1501 LED；逐段拆解 |
| TwinCAT 拒绝运行 | EL6070 dongle 不在 / 许可过期 | 看 dongle 灯；联系 Beckhoff |
| 急停后无法启动 | 急停按钮没复位 | 把按钮拉起来；GUI 复位 |
| 漏喷 | 阀响应延时太大 / 阈值太严 | 调 `valveOpenLatencyMs`；降 `xrayGangueMax` |
| 误喷 | 阈值太松 / 探测器干扰 | 升 `xrayGangueMax`；做暗场+亮场校正 |
| 探测器图像有竖条 | 单个 X-Card 故障 | 看 SDK demo 哪一段异常，更换该 X-Card |

## 安全规程（必读）

1. **辐射**：X 射线源不通电时绝对安全；通电时严禁开门、严禁靠近发射方向
2. **高压**：380V 主回路必须断开后才能开柜门；用万用表确认无电
3. **气路**：0.6 MPa 高压气，喷嘴方向严禁站人；储气罐每天放水
4. **机械**：皮带运行时严禁伸手；急停按钮位置必须 3 秒内可达
5. **操作**：开关机严格按"上电顺序"；故障必须先排查再复位

参考标准：
- GB/T 3836（爆炸性环境用电气设备）
- GBZ 117（工业 X 射线探伤卫生防护）
- GB 5226.1（机械安全 - 机械电气设备）
