### 2.3 控制核心（重大更新：不是传统 PLC！）

**Beckhoff TwinCAT 3 + EtherCAT 系统**（供货单位：山西永创自动化工程有限公司，发货日期 2026-01-09）：

| 型号 | 品名 | 数量 | 功能 |
|---|---|---|---|
| **FC9022** | PCIe EtherCAT 主站卡 | 1 | 装入工控机 PCIe 槽，作为整个 EtherCAT 网络的主站 |
| **EK1501** | EtherCAT 耦合器（光纤口） | 2 | 将 EtherCAT 信号转为光纤，提高现场抗干扰能力 |
| **EL2828** | 8 路 24V 2A 数字量输出模块 | **20** | 20 × 8 = **160 路 DO**，覆盖电磁阀 + 其他 I/O |
| **EL9011** | EtherCAT 总线末端盖帽 | 2 | 端子排末端必须有 |
| **EL9410** | EtherCAT 24V 电源供给模块 | 4 | 给端子总线供电 |
| **EL6070** | TwinCAT 许可密钥端子 | 1 | 硬件 Dongle，存储软件授权 |
| **TC1100-0291** | TwinCAT 3 PLC Runtime 软件 | 1 | 注册码 00386449 |
| **CU1521-0000** | USB EtherCAT 扩展耦合器 | 1 | 扩展接口 |

**架构含义**：
- 工控机安装 FC9022 PCIe 卡 → 驱动 EtherCAT 网络（1ms 实时周期）
- TwinCAT 3 Runtime 运行在同一台工控机上，处理实时 I/O
- **EL2828 × 20 = 160 路 DO**：推测 8 模块（64 路）用于气枪阀，其余 96 路用于皮带、信号灯等
- 上位机软件（Qt 应用）通过 **ADS（Automation Device Specification）协议（TCP/IP）** 与 TwinCAT 通信

**系统推算**：
- 17 块 X-Card × （每块像素数）= 完整探测器总像素
- Detection Technology 典型配置：每块 128 像素 × 800μm 间距 ≈ 102mm/块 × 17 = 1.74m 覆盖宽度（适配矿用宽皮带）
- **X-GCU GT** 是软件通信的唯一入口，通过 Aurora X-Link 总线汇聚所有模块数据
- 与 PC 的接口：Detection Technology 提供专有 SDK（`Aurora SDK`），这正是旧项目 `XLibDll.lib` 的来源！

**SDK 获取**：联系 Detection Technology（www.deetee.fi）或供方（地太科特北京）索要 Aurora SDK / GCU API Manual
