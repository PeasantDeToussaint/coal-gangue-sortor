## 3. 传感与采集

### 3.1 X 射线发射 + 探测
- **X 射线源**：装在 `光机防爆箱` 内（具体型号待铭牌确认）
- **线阵探测器**：黑色长条，约 1.1 m 长，装在 `探测器防爆箱` 内
  - 装机容量约 100 W 左右
  - **驱动协议**：旧项目用过 `XLibDll.lib`（Windows 闭源），具体厂家待确认
- **吹粉尘电磁阀**（100 W）：定时喷气清洁探测器视窗

### 3.2 凌云光（Lingyun Optics）工业相机模组（已到货）
照片来源：`照片/凌云光/` + `照片/集成相机与光源内部/`。

- **相机本体**：银色金属外壳，长方形视窗（线阵或区域），带散热鳍片 + 风扇
- **接口**：圆形多针航空插头 × 2（推测电源 + GigE/Camera Link）
- **电缆**：蓝色 GigE 千兆网线 + 黑色电源线
- **铭牌待补**：现场拍清

### 3.3 集成式光源（"光筒1100"）
- **标签**：`V2-12-638-520-450-200-0.22-1.5  SN:00232`
- **外形**：蓝色阳极氧化铝外壳，内部为 LED 阵列 + 透镜（线阵照明）
- **长度推测**：1100 mm（型号"光筒1100"）
- **作用**：为线阵相机提供高均匀度线光源
- **散热**：被动（内部见 PCB 与电感）

### 3.4 光电触发传感器
- 安装在皮带入口
- 输出：24V 干接点，物料经过时上升沿
- 走线：→ PLC（DI）→ PC（同步信号）

## 4. 执行机构

### 4.1 高速电磁阀
- **型号**：`DF8-2024-10`（合肥坤双光电，规格 `KS-DF8(12/6)`）
- **数量**：32 套（送货单 2024-10-31）
- **结构**：每套 4 气口阀岛 + 4 根彩色控制线（推测 24 V 直驱）
- **响应时间**：典型 5–15 ms（高速气阀级）

### 4.2 分气排
照片+手稿来源：`照片/分气排/`。

- **板材**：60 × 30 mm 钢板（手稿）
- **孔数**：约 26 孔 / 排，× 2 排 ≈ 52 孔实际接通
- **孔间距**：~ 30 mm
- **总长**：~ 860 mm（手稿标注）
- **通径**：~ 5/2 mm（手稿）

### 4.3 喷嘴 / 气路
- **气嘴**：`气枪方案三/气嘴.SLDPRT`
- **进气接头**：`进气接头.SLDPRT`
- **气源压力**：典型 0.5–0.8 MPa（待确认）

## 7. 已知未知点（→ 见 `protocol-questions.md`）

1. **FaDriver-64 串口协议** — 决定整个气枪链路能否打通
2. **凌云光相机型号 / SDK** — 决定相机集成路线
3. **PLC 品牌型号** — 决定 PLC 通信协议（西门子 S7 / 三菱 MC / 汇川 Modbus / 信捷 …）
4. **X 射线源型号** — 决定 SDK 与功率/能量参数
5. **皮带与喷嘴的实际几何距离** — 决定时序公式参数
6. **探测器扫描频率（行频）** — 决定数据流速率
