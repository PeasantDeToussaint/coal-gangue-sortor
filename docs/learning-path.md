# 新人工程师 4 周学习路线

> 你是刚入职的工程师，目标：**通过复刻这台煤矸石分选机，建立"软件 + 电气 + 机械 + 工艺"的整机思维**。

## 核心心法

> "先把整机在脑子里跑通一遍，再上现场。"

把这一步做扎实，现场遇到任何问题你都能定位到具体子系统。这就是为什么 Phase 0–2 全部是"无硬件可执行"——它们是你的"思维仿真器"。

---

## 第 1 周：读资料 + 跑通 Mock

### 目标
- 看懂整机信号链
- 跑起本仓库的 Mock 版软件
- 在 README 里能用自己的话画出系统架构图

### 任务
- [ ] 通读 `docs/hardware/inventory.md`（盘点）
- [ ] 通读 `docs/hardware/io-table.md`（信号契约）
- [ ] 用 SolidWorks Viewer / eDrawings 打开 `煤矸总装.SLDASM`，转一圈
- [ ] 把电气图（`配电柜/2.泓博.pdf`）打印出来贴墙上
- [ ] 精读论文 `智能分选过程中煤矸X射线识别技术的研究.pdf` 第 1–3 章（基础原理）
- [ ] **跑通**：`cd coal-gangue-sorter && cmake -B build && cmake --build build && ./build/app/coal_gangue_sorter --mock`
  - 看到 X 射线 / 相机假数据流
  - 看到 64 路喷嘴矩阵随机点亮
  - 验证你"理解了信号链"
- [ ] 写一段 200 字日记：你认为系统最关键的 3 个参数是什么？

### 产出
- 你画的架构图（可以贴在 `docs/sketches/` 里）
- 思维笔记：列出 5 个你还没搞懂的问题

## 第 3 周：通信调试（最难，也最学东西）

### 目标
- 用 Beckhoff ADS + EL2828 打通 1 路喷嘴（与 `ValveDriverEL2828` 一致）
- 拿到相机 SDK 并采到第一帧

### 任务
- [ ] 阅读 [`docs/hardware/protocols/beckhoff-ads.md`](docs/hardware/protocols/beckhoff-ads.md) 与 TwinCAT 侧 GVL 变量约定（如 `MAIN.bValveCh01`）
- [ ] 确认上位机能 `ping` 通 PLC，ADS 端口（默认 48898）未被防火墙拦截
- [ ] 用 TwinCAT 或上位机测试写 `bValveCh01`，让喷嘴 1 喷气 100 ms
- [ ] **关键时刻**：第一次听到喷嘴响——记住这个声音
- [ ] 跑通 `ValveDriverEL2828::schedule` / `selfTest`（或先用 PLC 强制置位验证气路）
- [ ] 接凌云光相机：扫描 QR 码 → 找 SDK → 跑通 `getFrame()`
- [ ] 把相机和 X 射线探测器的"行同步"问题想清楚（论文第 4 章帮你）
- [ ] 接 PLC：用 Modbus Poll 工具试探，找出真正的协议
- [ ] **64 路逐个点亮自检**：写一个`tools/nozzle_self_test.py`，逐个吹 200 ms

### 产出
- 视频：64 路喷嘴依次喷气
- `docs/hardware/beckhoff-valve-io.md`（或等价笔记）：记录 GVL 符号、ADS NetId、各通道与端子对应关系
- 单元测试：继续扩展 `tests/` 中与 `PipelineEngine` / Mock 阀驱动相关的用例

### 第 3 周末检查清单
- [ ] 我能让任意指定的喷嘴在指定时刻喷指定时长吗？
- [ ] 我能从相机和 X 射线同步采到一帧吗？
- [ ] 我能让皮带跑起来并设定速度吗？

如果三项都 ✅，第 4 周就轻松了。

## 第 4 周：标定 + 试运行

### 目标
- 完成皮带速度、几何距离、阀响应的现场标定
- 跑通"放矸石→识别→喷射"的端到端

### 任务
- [ ] 用 `tools/calibrate_belt.py` 标定皮带速度（变频频率 vs 实际线速度）
- [ ] 用秒表+标定块测量探测中心到喷嘴中心距离 `L_sd`
- [ ] 用高速相机或示波器测 DF8 阀响应延时
- [ ] 把所有标定参数写进 `config/config.xml`
- [ ] 准备 10 块煤 + 10 块矸石做样本
- [ ] 单块样本试运行：每次只放 1 块，观察识别 + 喷射
- [ ] 调整阈值，直到识别率 > 95%
- [ ] 混合试运行：5 煤 + 5 矸混合
- [ ] 写《现场试运行报告》：识别率、误吹率、漏吹率、节拍

### 产出
- `docs/calibration-report.md`（你的第一个工程报告）
- 一段试运行视频
- 改进建议清单（任何你觉得设计可以更好的地方）

## 学习心法（来自带过新人无数次的师傅们）

1. **拍照是最好的笔记**：一张铭牌照片胜过十页 Word
2. **示波器和万用表是你最好的朋友**：信号有没有，先看波形
3. **故障 90% 来自接线**：插头、屏蔽地、24V 公共端
4. **配电柜不是禁地**：但通电下手摸前**必须先听师傅讲一遍**
5. **永远在算法之前先做 Mock**：不要被硬件 bug 把算法 bug 掩盖了
6. **每天记一行日记**：今天我懂了什么 / 还不懂什么
7. **代码可以重构，安全不能**：X射线 + 380V + 高压气，每一项都能伤人
