# Qt GUI 构建说明

> Phase 6 产出：`coal_gangue_sorter_gui` Qt 桌面应用。  
> 兼容 Qt 5.12+ 与 Qt 6.x，CMake 自动选择。

## 依赖

| 平台 | 安装方式 |
|---|---|
| macOS | `brew install qt@6` 或 `brew install qt@5` |
| Ubuntu | `sudo apt install qt6-base-dev` 或 `qtbase5-dev` |
| Windows | 从 https://www.qt.io/download 下载 Qt Online Installer |

## 编译

```bash
cd coal-gangue-sorter
cmake -B build -DCGS_BUILD_GUI=ON
cmake --build build -j
./build/app/coal_gangue_sorter_gui
```

如果 CMake 找不到 Qt，加：
```bash
cmake -B build -DCGS_BUILD_GUI=ON -DCMAKE_PREFIX_PATH=/opt/homebrew/opt/qt@6
```

## 命令行参数

| 参数 | 含义 |
|---|---|
| `--mock` | 使用 Mock 硬件（默认） |
| `--real` | 切到真实硬件适配器（需要相应编译开关） |

## 文件清单

```

├── main_gui.cpp           程序入口（拼装硬件 + 引擎 + 主窗口）
├── MainWindow.h/.cpp      主窗口与工具栏
├── XRayWaterfallView.*    X 射线瀑布图（线阵实时滚动）
├── NozzleMatrixView.*     8x8 喷嘴矩阵（带衰减效果）
├── ConfigPanel.*          实时调参面板
└── StatsPanel.*           运行统计面板
```

## 设计要点

- **MVC 分离**：`PipelineEngine`（无 Qt）做编排，UI 只显示快照和统计
- **线程安全**：`PipelineFrameSnapshot` 通过回调跨线程传递；瀑布图与喷嘴矩阵各自加锁
- **零依赖于硬件**：默认 Mock，加 `-DCGS_HAS_SERIAL=ON -DCGS_HAS_BECKHOFF_ADS=ON` 等即可换成真实硬件
- **实时调参**：分类阈值、喷嘴时序在运行中改即生效
